# Contributing

Thanks for reading. This repo is a case study: documentation only, the code is private.

- **Corrections and questions:** open an issue with a template. Name the file and section.
- **Pull requests:** small fixes to wording, typos or broken links are welcome. Say what changed and why.
- **Before opening one:** make sure CI is green (it runs gitleaks on the full history).
- **Security issues:** never in public. See [SECURITY.md](SECURITY.md).

I answer issues within a few days.
