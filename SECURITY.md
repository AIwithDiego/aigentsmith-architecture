# Security policy

## Reporting a vulnerability

This repository is documentation only; the AIgentSmith source code is private.

If you believe something here exposes a vulnerability in a system it describes, or that a commit contains something it shouldn't, email **diego@aiwithdiego.com** with the file, the line and the details. Do not open a public issue or pull request for it.

I'll acknowledge your report within 5 working days.

## Supported versions

Only the latest commit on `main` is supported.
